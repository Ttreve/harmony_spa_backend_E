# Harmony Spa – Frontend v2

React + Vite (JavaScript) con react-router. Estilo verde/crema con tipografía Playfair Display + DM Sans.

```bash
npm install
cp .env.example .env   # Windows: copy .env.example .env
npm run dev
```

Rutas: `/` · `/login` · `/superadmin/dashboard` · `/superadmin/usuarios` · `/perfil`
(y `/admin|esteticista|cliente/dashboard` según el rol).
